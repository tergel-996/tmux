# Telescope-style Session Switcher

## Summary

A fuzzy session switcher for tmux that mimics Neovim Telescope's live grep UX. Press `prefix + S`, type to fuzzy-filter session names, see a preview of the selected session's windows, and press Enter to switch.

## Trigger

- Keybinding: `prefix + S` (replaces current `choose-session` binding)
- Opens a `tmux display-popup` centered on screen

## Popup

- Size: 80% width, 60% height, centered
- Runs fzf inside the popup
- Escape or Ctrl-C dismisses the popup with no action

## fzf Layout

- **Left side:** Fuzzy-filtered list of session names
  - Excludes the current session (no point switching to yourself)
  - If no other sessions exist, display a message and exit
- **Right side:** Preview pane showing details of the highlighted session

## Preview Pane Content

For the highlighted session, show its window list:

```
Windows:
  1: nvim (~/projects/app) [nvim]
  2: terminal (~/projects/app) [zsh]
  3: logs (/var/log) [tail]
```

Each line: window index, window name, pane current path, running command.

Preview is generated by querying `tmux list-windows` with a format string.

## Behavior

1. User presses `prefix + S`
2. Popup appears with all sessions (minus current) listed
3. User types to fuzzy-filter by session name
4. Preview pane updates as selection changes
5. Enter: switch to selected session, popup closes
6. Escape/Ctrl-C: cancel, popup closes

## Files

| File | Action | Purpose |
|------|--------|---------|
| `scripts/session-switcher.sh` | Create | fzf + preview logic (~15 lines) |
| `tmux.conf` | Modify | Replace `bind S choose-session` with `bind S display-popup` |

## Dependencies

- `fzf` -- already required by tmux-fzf plugin
- `tmux` 3.2+ -- required for `display-popup`

## Edge Cases

- **Single session:** If the current session is the only one, show a brief message ("No other sessions") and exit cleanly
- **Session created/destroyed while popup is open:** fzf snapshot is taken at popup launch; this is acceptable since the popup is short-lived
- **Long session names:** fzf handles horizontal scrolling natively
